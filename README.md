# Student Management System

This is a Java project that connects to MySQL database using JDBC.

## Features
- Add Student
- View Students
- Update Student
- Delete Student

## Technologies Used
- Java
- MySQL
- JDBC
- VS Code

## Project Structure
DBConnection.java – Database connection  
StudentDAO.java – CRUD operations  
MainApp.java – Menu driven program

## How to Run
1. Install Java
2. Install MySQL
3. Create database "studentdb"
4. Run the Java files
